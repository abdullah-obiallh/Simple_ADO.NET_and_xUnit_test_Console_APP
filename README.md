# Simple ADO.NET and xUnit Test Console Application

A basic console application demonstrating CRUD (Create, Read, Update, Delete) operations using ADO.NET on .NET Framework, accompanied by unit testing implemented with xUnit.

## Project Overview

This project is built to practice and demonstrate fundamental backend concepts without relying on heavy ORMs like Entity Framework. It focuses on direct database interaction using ADO.NET and validating code logic through automated unit tests.

## Technologies Used

- Language: C# (.NET Framework)
- Data Access: ADO.NET (SqlCommand, SqlConnection, SqlDataReader)
- Testing Framework: xUnit
- Database: Microsoft SQL Server

## Features

- Complete CRUD operations (Insert, Select, Update, Delete) via a console interface.
- Direct SQL command execution and connection management.
- Automated unit testing for business/data logic validation.
